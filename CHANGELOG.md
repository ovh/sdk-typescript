## 0.2.0 (2026-11-17)

First release.

### SDK core

- First release of the TypeScript SDK, generated by sdkgen from the OVHcloud API's OAS3 specs.
- OAuth2 service accounts (client credentials), from `OVH_CLIENT_ID`, `OVH_CLIENT_SECRET` and
  `OVH_REGION`, or your own token source.
- One property per API section on the client: `client.vrack`. Each section is also a subpath
  of the package (`@ovhcloud/sdk/api/vrack`), for smaller bundles with `@ovhcloud/sdk/core`.
- Types of the JSON the API sends and takes, with its own property names. Open enums.
- Typed errors for each common status: `NotFoundError`, `ForbiddenError`... An error names
  the operation and, on a 401 or 403, the IAM actions it needs.
- Async iterators over v2 lists paginated by cursor (`allX`), and over v1 lists of IDs.
- `waitReady`, `waitTask`, `waitGone` and `wait` for asynchronous work.
- `readOnly` and `allowedOperations` client options, checked before anything is sent.
- Retries, off by default, with the same limits as the Go SDK.
- v2 requests send `X-Schemas-Version`: the contract the SDK was generated from, whatever the
  account's own setting.
- Request bodies take `<Type>Writable`, the type without its read-only fields, when the type
  has some. Field docs say which fields are read-only, and give the date and int64 formats.
- Raw calls: `client.get<T>(...)` and the other raw methods take the type of their result
  (not checked at run time). `path(template, params)` builds a path and escapes its values.
- A path without `/v1/` or `/v2/` (`/me`, `/1.0/me`) is refused with `InvalidRequestError`,
  with the path to use.
- `RequestTimeoutError`, a `TransportError`, for a request that took more than its timeout.
  The client's `timeout` also bounds the token request.
- `retrySleep` client option, to skip the waits between retries in tests.
- `ApiError` has `bodyText` and `toJSON()`, so `JSON.stringify(err)` gives its fields.
- Small programs in `examples/`, and the docs (`llms.txt`, `AGENTS.md`, `index/`) exported by
  the package: `require.resolve("@ovhcloud/sdk/llms.txt")`.
- No runtime dependency: `fetch` only. Runs on Node.js 22.12 or later, Deno and Bun. CommonJS
  programs can `require` it. Tested on Node.js 22, 24 and 26.
